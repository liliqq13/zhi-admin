# 智路哨兵 APP V1.1 · 三个车辆优化版

网页版来自用户提供的安卓 APK 内置页面，保留三辆车图片、车型切换、路线、预警与设备页面。

平台入口：`./index.html`。支持 GitHub Pages 子目录 `/zhi-admin/app-v1-1/`；脚本、图片、PWA 与缓存路径均为相对路径。

点击“进入安全平台”即可作为访客浏览五个页面，无需账号。此公开入口只载入页面内置的项目测试记录，设备后端地址为空，不连接真实设备的受保护接口。

在线地图与天气已配置，无需填写服务密钥：

- 地图：本地随包加载 Leaflet 1.9.4，在线请求 OpenStreetMap 底图，使用 OSRM 道路规划。地图支持三车切换、缩放、完整显示路线和轨迹预览。旧高德测试点按 GCJ-02 近似转换为 WGS84；规划路线仅供项目演示，不是车辆实测定位或导航依据。
- 天气：Open-Meteo 当前模型天气，每 10 分钟更新；三辆车分别使用兴龙湖、凤凰湖和茶山竹海测试路线中心点。数据时间采用北京时间，能见度标记为小时预报。天气独立展示，不改写内置测试事件或安全风险记录。
- 异常处理：进入地图页自动连接在线底图，底图首次失败后按 5/15/30 秒间隔最多自动重连三次；回到地图、恢复前台或联网时重新尝试。只加载当前可见区域，后台与离线时停止自动重试。道路规划失败保留底图，必要时使用明确标记的测试连线。天气失败时展示带时间的缓存或“暂无数据”，不将预置测试值标为当前天气。
- 缓存：应用外壳及本地组件可离线使用；外部瓦片、道路和天气请求不进入 Service Worker 缓存。OSRM 按车型缓存规划结果 7 天，并对请求限频；天气缓存最多保留 24 小时，过期状态单独标记。

当前使用公共免费服务，适用于此项目演示；商业或大规模使用前应核对服务条款并配置合适的服务。地图署名保留在地图可见区域，天气卡片保留数据来源链接。已有安装版可在“我的 → 更新并重新打开”应用更新。

服务文档：
- https://operations.osmfoundation.org/policies/tiles/
- https://project-osrm.org/docs/v5.24.0/api/
- https://open-meteo.com/en/docs

不要将私有服务密钥提交到公开仓库。

## 2026-09-25 地图连接修复

底图与道路规划独立处理：道路规划失败不会隐藏已经加载的在线底图；可用的道路缓存会保留，没有道路结果时明确显示虚线测试连线。网络恢复或手动重试可重新加载失败的底图，并对重试限频。状态栏分别说明底图连接和道路规划状态。

“在高德查看路段”使用高德官方 URI 单点标注入口，在新页面查看当前测试路线中心点；不读取用户的手机定位，不自动跳转，也不将外部地图表示为应用内已加载。

新版应用外壳完整下载后自动激活，关闭旧页面再扫描原二维码即可使用新版本；正在浏览的页面不会被强制刷新，新运行组件提供可见的更新提示。

### 自动连接补充

地图页、车辆切换和返回前台统一使用在线连接流程，避免已有地图对象阻止失败瓦片重试。地图控制按钮改为“重新连接在线地图”，不会再将正常在线底图切换成本地模式。公共地图服务仍需设备网络可达，超过重试次数会明确显示连接失败；不会将本地示意标成在线地图。部署路径仍为 `/zhi-admin/app-v1-1/`，原二维码继续使用。

图片按原始字节提取至 `assets/`，未重新压缩；APP 显示版本统一为 1.1.0。
